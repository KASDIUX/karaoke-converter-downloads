# 歌唱機歌曲轉檔工具

此儲存庫只提供 Windows 免安裝版下載，不含本專案原始碼。

## 下載與使用

前往 [最新版本下載頁](https://github.com/KASDIUX/karaoke-converter-downloads/releases/latest)，下載名稱包含 `windows-x64.zip` 的完整套件，全部解壓縮後開啟「音王歌曲轉檔工具.exe」。請保留資料夾內的執行元件。

支援 Windows 10／11 64 位元，不需要安裝 Python。若要檢查下載完整性，可使用隨附的 `.sha256` 校驗碼。

解壓縮後最外層只有三項：

```text
音王歌曲轉檔工具.exe
程式資料/
使用說明.html
```

雙擊主程式即可使用，請將它與「程式資料」放在一起。雙擊「使用說明.html」可離線查看圖文教學，對照實際介面完成第一次解壓縮、搜尋選歌、貼網址下載、聲音處理及 USB 操作。預設完成歌曲存於「程式資料/已轉換歌曲」，也可在介面另選儲存位置。

GitHub 自動產生的「Source code」壓縮檔只有本頁說明，並非可執行程式，也不含應用程式原始碼。

## 功能

- 批次下載、歌名搜尋、候選影片預覽。
- 最高 1080p，來源畫質較低時保留來源畫質。
- AI 製作左伴奏／右完整原唱，也可逐首保留或交換既有聲道。
- 自訂分類名稱與歌名，輸出適合 USB 播放的 MP4。

AI 分離可能殘留人聲；來源須含原唱。歌唱機相容性請先用少量歌曲試播。請處理你有權下載及轉換的內容。

套件內第三方元件的授權與來源列於 `程式資料/第三方元件.txt` 及 `程式資料/licenses`，請保留。
